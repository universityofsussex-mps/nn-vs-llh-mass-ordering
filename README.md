# nn-vs-llh-mass-ordering

This is a python package that compares a neural-network (NN) classifier against the standard log-likelihood minimisation for distinguishing the **Normal Ordering (NO)** and **Inverted Ordering (IO)** of neutrino masses. Several refinements to this toy study could be explored in future work. The Gaussian flux approximation and the 22-bin layout used here were chosen primarily for simplicity. The use of a more accurate flux model (the NOvA beam flux is narrow-band) and a finer or jointly-learned binning, tuned for classifier performance, could reveal additional spectral structure for the network to exploit.  Alternative architectures, such as convolutional or graph-based networks, may extract subtle features from high-dimensional oscillation data more effectively than the feed-forward network used here.

This code accompanies the paper:

> T.J.C. Bezerra, L. Asquith, E. Bannister, and W. Shorrock, *Predicting the Neutrino Mass Ordering Using Neural Networks*, [arXiv:2606.03745](https://arxiv.org/abs/2606.03745).

---

## Physics overview

Neutrino oscillations depend on the sign of the mass-squared difference $\Delta m^2_{32} = m_3^2 - m_2^2$:
* **Normal Ordering (NO):** $\Delta m^2_{32} > 0$
* **Inverted Ordering (IO):** $\Delta m^2_{32} < 0$

The analysis uses pseudo-data from a NOvA-like long-baseline experiment (L = 810 km) with four detection channels: $\nu_\mu$ disappearance, $\bar\nu_\mu$ disappearance, $\nu_e$ appearance, and $\bar\nu_e$ appearance.  For each Poisson-fluctuated pseudo-dataset the package applies two classifiers:

1. **LLH fit** — minimise −2 ln L independently for NO and IO; the ordering with the smaller minimum is preferred.
2. **NN classifier** — a two-hidden-layer dense network that outputs a score in [0, 1], with 1 = NO and 0 = IO.

Performance is compared via the **Receiver Operating Characteristic (ROC)** curve and the True/False Positive Rates at the operating point chosen by maximising the F1 score.

## Package structure

```
nn-vs-llh-mass-ordering/
├── oscillations.py        # 3-flavour oscillation probabilities (NuFast)
├── spectrum.py            # 3-flavour energy spectrum generation
├── fitting.py             # 3-flavour Poisson LLH + chi² fitting
├── neural_network.py      # 3-flavour NN classifier (NO vs IO)
├── biprobability.py       # Bi-probability diagram (Fig 1)
├── two_flavor.py          # 2-flavour physics, NN regressor, LLH fit
├── plotting.py            # Shared visualisation utilities
├── run_comparison.py      # 3-flavour analysis pipeline (Figs 6 & 7 inputs)
├── run_2f_comparison.py   # 2-flavour analysis pipeline (Fig 4 right inputs)
├── make_figures.py        # Plotting only — renders all 7 figures
└── requirements.txt       # Python package dependencies
```

The two `run_*_comparison.py` scripts perform all heavy computation and save
the intermediate results to disk; `make_figures.py` only reads those files
and renders figures.  Each analysis script automatically skips steps whose
output files already exist.

## Installation

Clone the repository:

```bash
git clone https://github.com/universityofsussex-mps/nn-vs-llh-mass-ordering.git
cd nn-vs-llh-mass-ordering
```

We recommend a dedicated virtual environment.

```bash
# Create and activate environment
python -m venv env
source env/bin/activate    # on Windows: env\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

The code has been tested with Python 3.10–3.12 and TensorFlow 2.13–2.17.

## Reproducing the paper figures

All seven paper figures are produced by `make_figures.py`:

```
Fig 1   Bi-probability diagram                   — analytic, no files needed
Fig 2   NO vs IO best-fit spectra (4 channels)   — analytic, no files needed
Fig 3   Δχ² profile in Δm²₃₂                     — NO Asimov spectrum, no files needed
Fig 4   Left:  2-flavour energy spectra          — no files needed
        Right: NN vs LLH Δm² regression scatter  — reads 2f_results.pkl
Fig 5   Left:  NN classifier score histogram     — needs --model and --data
        Right: Training-data ROC curve           — needs --model and --data
Fig 6   NN score vs LLH Δm²₃₂ scatter plot       — reads NO_output.pkl + IO_output.pkl
Fig 7   Full ROC curve + LLH operating point     — reads NO_output.pkl + IO_output.pkl
extra   Bootstrap diagnostics (not in the paper) — reads 2f_results.pkl
          Extra_nll_profile.pdf   (LLH NLL profile + 1σ band)
          Extra_nn_bootstrap.pdf  (NN-bootstrap Δm² distribution)
```

Figs 4 and 5 are saved as two PDFs each (`FigN_left_*.pdf` / `FigN_right_*.pdf`).

Figs 6–7 require `NO_output.pkl` / `IO_output.pkl` produced by
`run_comparison.py`; Fig 4 right and the `extra` plots require
`2f_results.pkl` produced by `run_2f_comparison.py` (see
[Quick start](#quick-start)).  If a required file is missing or misnamed,
`make_figures.py` tells you exactly which file it cannot find and how to
generate it.  `--fig all` includes the extras; pass `--fig 1,2,3,4,5,6,7` to
skip them.

```bash
# Figures that need no pre-computed files:
python make_figures.py --fig 1,2,3

# NN diagnostic figure (5):
python make_figures.py --fig 5 --model MO_model.h5 --data train_sample.pkl

# Just the bootstrap diagnostics:
python make_figures.py --fig extra

# All figures (requires NO_output.pkl, IO_output.pkl, 2f_results.pkl):
python make_figures.py --fig all --model MO_model.h5 --data train_sample.pkl

# Pre-computed files in a sub-directory:
python make_figures.py --fig all --model MO_model.h5 --data train_sample.pkl \
                       --results-dir results/

# Pop up an interactive matplotlib window for every figure (in addition to saving):
python make_figures.py --fig all --model MO_model.h5 --data train_sample.pkl --show
```

By default `make_figures.py` is headless — every figure is written to
`--output-dir` and no GUI windows appear.  Use `--show` for visual inspection.

## Quick start

The package contains two independent analysis pipelines:

| Pipeline           | Script                  | Produces                            | Used by      |
|--------------------|-------------------------|-------------------------------------|--------------|
| 3-flavour (NO/IO)  | `run_comparison.py`     | `NO_output.pkl`, `IO_output.pkl`    | Figs 6 & 7   |
| 2-flavour $\Delta m^2$ fit  | `run_2f_comparison.py`  | `2f_results.pkl`                    | Fig 4 right  |

Both scripts use **automatic skip-if-exists logic** for every step, so you
can resume an interrupted run without restarting from scratch.  Once the
relevant `.pkl` files exist, run `make_figures.py` to render the figures.

### 3-flavour pipeline

#### 1. Results already computed

If `NO_output.pkl` and `IO_output.pkl` are already present, no arguments are
needed — the script loads them and prints the summary:

```bash
python run_comparison.py
```

#### 2. Run with a pre-trained model and saved training data

```bash
python run_comparison.py --model MO_model.h5 --data train_sample.pkl
```

Training is skipped if the model file exists; toy experiments are skipped if
the output files exist.  Then produce figures:

```bash
python make_figures.py --fig all --model MO_model.h5 --data train_sample.pkl
```

#### 3. Train from scratch

If neither the training data nor the model exist, the script generates
everything automatically.  Expect roughly **1 h end-to-end on a typical
multi-core laptop**: ~30–40 min to generate the 2 M training spectra, plus
model training and 2000 toy experiments.  Both the training-spectra
generation and the toy-experiment LLH fits are parallelised across
`--n-workers` cores (default `os.cpu_count()`).  Training holds out a
fraction of the data given by `--val-split` (default 0.1) for validation,
and stops early once `val_loss` has not improved for `--patience`
(default 20) epochs; the saved model is the best-val-loss checkpoint.

```bash
python run_comparison.py --model MO_model.h5
```

For a quick end-to-end test with a smaller dataset:

```bash
python run_comparison.py --model MO_model.h5 \
    --nsamples-train 50000 --epochs 200 --nsamp 100
```

To effectively disable early stopping and run the full epoch budget, pass
a large patience, e.g. `--patience 9999`.  To disable the validation
hold-out entirely (which also disables early stopping), pass
`--val-split 0`.

#### 4. Forcing reruns of individual steps

Three flags control which cached files are reused vs regenerated:

| Flag           | `train_sample.pkl` | model `.h5`  | `NO_output.pkl` / `IO_output.pkl` |
|----------------|--------------------|--------------|-----------------------------------|
| (no flag)      | reused if exists   | reused       | reused → **whole pipeline skipped** |
| `--rerun-toys` | **reused**         | **reused**   | **regenerated**                   |
| `--retrain`    | **reused**         | **regenerated** | **regenerated**                |
| `--force`      | regenerated        | regenerated  | regenerated                       |

Typical use:

```bash
# Just rerun the 2000 toy experiments (e.g. after changing the LLH fit code):
python run_comparison.py --model MO_model.h5 --data train_sample.pkl --rerun-toys

# Reuse the existing 2 M-sample training set but retrain the NN + rerun toys:
python run_comparison.py --model MO_model.h5 --data train_sample.pkl --retrain

# Full rerun, including the slow training-sample regeneration (~30 min):
python run_comparison.py --model MO_model.h5 --data train_sample.pkl --force
```

### 2-flavour pipeline ($\Delta m^2$ regression benchmark)

Trains a dense NN **regressor** on 2-flavour $\nu_\mu$ disappearance histograms and
compares its best-fit $\Delta m^2$ to a standard Poisson LLH fit using two
complementary tests at $\Delta m^2 = 2.45 \times 10^{-3}~\mathrm{eV}^2$:

1. **1000 pseudo-experiments** — independent Poisson realisations of the
   Asimov spectrum, each fit by both NN and LLH.  Yields the bulk
   comparison shown in Fig 4 right.
2. **Single-experiment bootstrap** — one pseudo-experiment is drawn, then
   Poisson-resampled `--n-bootstrap` times (default 1000) to get an
   empirical 1σ band for the NN's $\Delta m^2$ prediction (the NN itself doesn't
   provide one).  An LLH NLL scan on the same single experiment gives the
   reference ±1σ from Wilks' theorem.  This shows that **both** methods
   produce comparable single-experiment uncertainties, suitable for
   quoting in the paper.

Both steps are stored in `2f_results.pkl` (1000-toy results in `a_fit` /
`a_nn`, bootstrap data under a `bootstrap` key) and the trained Keras model
is saved at `--model`.

```bash
# First time — train + run both tests + save 2f_results.pkl:
python run_2f_comparison.py --model dm2_model.h5

# Just print the summary if results already exist:
python run_2f_comparison.py

# Quick smoke test:
python run_2f_comparison.py --model dm2_model.h5 \
    --nsamples-train 100000 --epochs 30 --nsamp 100 --n-bootstrap 100
```

The script prints a summary block that includes the numbers to quote:

```
  LLH (NLL scan):                 Δm² = best_fit (-σ_lo / +σ_hi) ×10⁻³ eV²
  LLH (bootstrap median + 68 %):  Δm² = median   (-σ_lo / +σ_hi) ×10⁻³ eV²
  NN  (bootstrap median + 68 %):  Δm² = median   (-σ_lo / +σ_hi) ×10⁻³ eV²
```

Then render Fig 4 plus the bootstrap diagnostic plots:

```bash
python make_figures.py --fig 4,extra
```

### `two_flavor.py`

```python
from two_flavor import (
    make_bins, gaussian_flux, oscillated_spectrum,
    generate_histograms, fit_dm2, dm2_uncertainty_scan,
    create_regressor, train_regressor, DM2_REF,
)

# Standard 10-bin energy grid (1.0–3.0 GeV)
bin_edges, bin_centers = make_bins()

# Asimov spectrum at Δm² = 2.45e-3
mu = oscillated_spectrum(bin_centers, dm2=DM2_REF)

# 1 million training samples with random Δm² ∈ [1e-3, 4e-3]
X, y = generate_histograms(1_000_000, bin_centers, dm2=0.0)

# LLH fit on a single pseudo-experiment (returns NaN on hard failure)
hist, _ = generate_histograms(1, bin_centers, dm2=DM2_REF)
dm2_hat = fit_dm2(hist[0].astype(int), bin_centers)

# ±1σ uncertainty from a Wilks' theorem NLL scan (ΔNLL = 1)
sigma_lo, sigma_hi, scan_dm2, scan_nll = dm2_uncertainty_scan(
    hist[0].astype(int), bin_centers, dm2_hat,
)
```

Self-contained 2-flavour benchmark module: physics ($\nu_\mu \to \nu_\mu$ vacuum survival,
Gaussian flux model), data generation, Poisson LLH fitter with optional
uncertainty scan, and a dense NN regressor.  Used by `run_2f_comparison.py`
and Fig 4 (plus the bootstrap `extra` plots) in `make_figures.py`.
